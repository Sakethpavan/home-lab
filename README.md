# Homelab

## Hardware

- Raspberry Pi Zero 2 W
- Debian 13 (Trixie)
- Docker
- Docker Compose

## Planned Services

- Homepage
- Caddy
- File Browser
- Uptime Kuma
- Mosquitto MQTT
- Cloudflare Tunnel

## Directory Layout

configs/    -> Service configuration
data/       -> Persistent service data
scripts/    -> Utility scripts
docs/       -> Documentation
backups/    -> Backups
logs/       -> Host logs
